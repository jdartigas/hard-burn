# Credits for files in assets/ and js/stardata.js

- **Sound effects** (`assets/sfx/*.m4a`, v63): from Kenney's "Sci-Fi Sounds" and "Impact Sounds" packs, by Kenney
  (www.kenney.nl), Creative Commons Zero (CC0, public domain). Trimmed, faded, mixed to mono and converted to AAC.
  Sources: laserSmall, laserLarge, thrusterFire, forceField, explosionCrunch and lowFrequency_explosion (Sci-Fi Sounds);
  impactPunch_heavy, impactPlate_heavy and impactMetal_heavy (Impact Sounds).

Everything else in Laniakea's Edge is generated in code. These are real data, used so the sky and the planets
are where and what they really are.

- **Earth surface** (`assets/sol/earth.jpg`): NASA Visible Earth, Blue Marble, "land_shallow_topo_2048".
  Image by Reto Stöckli, NASA Earth Observatory. https://visibleearth.nasa.gov/images/57752 . Public domain (NASA).
- **Earth clouds** (`assets/sol/clouds.jpg`): NASA Visible Earth, Blue Marble clouds, "cloud_combined_2048",
  resized to 1024 x 512. https://visibleearth.nasa.gov/images/57747 . Public domain (NASA).
- **Moon surface** (`assets/sol/moon.jpg`): NASA Scientific Visualization Studio, CGI Moon Kit, LRO LROC colour
  map "lroc_color_poles_1k". https://svs.gsfc.nasa.gov/4720 . Public domain (NASA).
- **Mars** (`assets/sol/mars.jpg`): Viking MDIM 2.1 colour mosaic, USGS Astrogeology / NASA, via Wikimedia Commons
  ("Mars Viking MDIM21 ClrMosaic 1km.jpg"), resized to 2048 x 1024. Public domain.
- **Phobos** (`assets/sol/phobos.jpg`): Viking mosaic (DLR control), Planetary Data System / Phil Stooke, via Wikimedia
  Commons ("Phobos Viking Mosaic DLRcontrol 7200.jpg"), resized to 1024 x 512. Public domain.
- **Jupiter** (`assets/sol/jupiter.jpg`): Cassini cylindrical map, December 2000, NASA/JPL/Space Science Institute,
  PIA07782, via Wikimedia Commons, resized to 2048 x 1024. Public domain.
- **Io** (`assets/sol/io.jpg`): map projection PIA00319, NASA/JPL/USGS, via Wikimedia Commons, resized to 1024 x 512.
  Public domain.
- **Europa** (`assets/sol/europa.jpg`): Voyager and Galileo SSI global mosaic, USGS / Planetary Data System, via
  Wikimedia Commons. Public domain. Tinted cream in the game.
- **Callisto** (`assets/sol/callisto.jpg`): USGS Astrogeology global mosaic, via Wikimedia Commons, resized to
  1024 x 512. Public domain. Tinted brown-grey in the game.
- Ganymede and Deimos have no clean public global map; Ganymede's surface is drawn in code, Deimos shows as a point.
- **Stars** (`js/stardata.js`): HYG Database v4.1 by David Nash (astronexus),
  https://github.com/astronexus/HYG-Database . CC BY-SA 4.0; the derived subset is shared under the same license.
